# Private dice artwork

Files placed in this directory are local-only and excluded from Git.

Each monster collection expects one 256×256 lossless WebP named with its
lower-case slug, for example:

- `rathalos.webp`
- `dreadking-rathalos.webp`
- `zinogre.webp`
- `stygian-zinogre.webp`
- `fulgur-anjanath.webp`
- `dreadqueen-rathian.webp`

The Guild Pair is the only collection that needs two files (`rathian.webp` and
`rathalos.webp`). Every dedicated monster collection uses its own icon on both
special faces. Collections are registered independently, so a missing private
file disables only that monster's presets.
